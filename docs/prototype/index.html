③ 桌面版架构（一层封装，Agent Core 零改动）

┌────────────────────────────────────────────────────────────┐ │ Desktop Shell（Electron / Tauri） │ │ 窗口管理 · 原生菜单 · 文件对话框 · 系统托盘 · 自动更新 │ ├────────────────────────────────────────────────────────────┤ │ Renderer（React + TS，复用 TUI 的 hooks 资产） │ │ Sidebar / MessageList / Composer / CompletionPanel │ │ PermissionDialog / SettingsView / ExtensionsView │ └──────────────┬─────────────────────────────────────────────┘ │ IPC（类型化 API：invoke / event stream） ┌──────────────▼─────────────────────────────────────────────┐ │ Main（Node）＝ 复用 mcode CLI 内核，不改一行 │ │ agent/loop + harness（context/history/compaction/scheduler）│ │ tools/registry · permission/manager · sessions · plugins │ │ cli.tsx（Ink TUI）保留，与 Desktop 共享同一 Agent Core │ └────────────────────────────────────────────────────────────┘ 关键决策： 1. CLI 内核整体平移为 Main 进程库，TUI 与 GUI 双前端共享，保证能力 100% 对齐； 2. 流式输出 / 工具事件 / 权限请求 / 补全索引 全部走 IPC 事件流，Renderer 是纯视图； 3. ~/.mcode 目录结构不变（config.json / sessions / skills / plugins），CLI 与 Desktop 数据互通； 4. PUA / pua:on、异步文件扫描、多模态等近期 CLI 特性由同一 registry 提供，双端同步生效。
