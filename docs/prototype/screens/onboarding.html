🔌 配置模型供应商

统一走 OpenAI Responses 协议，通过 baseURL / model 接入任意厂商。apiKey 只存环境变量名，不落明文。
🤖自定义 Provider
baseURL + Responses 协议（GLM / DeepSeek / Qwen / OpenAI…）
🦙本地模型
Ollama / vLLM 本地端点
引用环境变量名而非密钥本体 · 桌面版提供系统 Keychain 可选项
带 multimodal 标记的模型才允许接收图片附件输入

🛡 默认权限模式

决定工具调用（bash / 写文件等）是否需要你确认。会话内随时 shift+tab 切换。
●passon（默认）
全自动放行，零打断。适合信任度高的日常开发
●manual
每个非只读工具执行前弹确认
●auto
白名单自动放行，其余确认
●plan
只读模式，只输出计划不落盘
⚠ passon 为全自动放行模式：bash / 写文件等破坏性操作将不经确认直接执行。请确认你了解此风险，或改选 manual / auto / plan。

✅ 初始化完成

已写入 ~/.mcode/config.json：
{
  "language": "zh_CN",
  "activeProvider": "zhipu",
  "providers": [{ "name": "zhipu", "baseURL": "https://open.bigmodel.cn/api/paas/v4",
                  "apiKeyEnv": "ZHIPU_API_KEY", "models": [...] }],
  "defaultMode": "passon"
}
